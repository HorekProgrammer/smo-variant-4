# Маппинг СМО на бизнес-домен

**Вариант 4 · Добров М. Г. · 5130904/40106**

| Элемент СМО | Бизнес-сущность | Класс / ответственность |
|---|---|---|
| Источник ИБ, ИЗ2 | Клиентская система клуба | `Source`: создаёт `Request`, независимо планирует следующую генерацию |
| Заявка | Аналитическое задание | `Request`: идентификатор, источник, данные, состояние и временные отметки |
| Буфер Д1ОЗ1 | Кольцевой буфер заданий | `RingBuffer`: массив слотов, УБ, очередь вставок |
| Диспетчер постановки | Модуль приёма заданий | `PlacementDispatcher`: принимает заявку, вставляет либо замещает ожидающую |
| Дисциплина отказа Д1ОО4 | Вытеснение задания при перегрузке | `RingBuffer.replaceLatest`: жертва с максимальным `queueOrder` до вставки новой |
| Диспетчер выбора | Планировщик заданий | `SelectionDispatcher`: согласует выбор заявки и свободного прибора |
| Выбор заявки Д2Б4 | Приоритет клуба, одно задание | `RingBuffer.popHighestPriority`: минимальный `sourceId`, затем максимальный `queueOrder` |
| Выбор прибора Д2П2 | Обход обработчиков по кольцу | `DevicePool`: массив приборов, УП; указатель изменяется после назначения |
| Прибор ПЗ1 | Серверный обработчик | `Device`: одна текущая заявка, интенсивность обслуживания μ |
| Обслуживание | Расчёт и сохранение отчёта | `Device.begin`, `Device.complete`; модель учитывает длительность операции |
| Выход после обслуживания | Готовый аналитический отчёт | `Request.COMPLETED`, фиксация времени и статистики |
| Выход по отказу | Отменённое ожидающее задание | `Request.EVICTED`, отказ относится к источнику вытесненной заявки |
| Модельное время | Ход имитационного эксперимента | `Simulation`, `EventCalendar`, `Event` |
| ОД1 | Наблюдение за состоянием сервиса | `StepView`: календарь, буфер, источники, приборы, УБ/УП, счётчики |
| ОР2 | Анализ конфигурации сервиса | `ExperimentRunner`, `ChartView`: серии прогонов и графики показателей |
| Статистика | Журнал результатов заданий | `Statistics`: генерации, отказы, обслуживания, времена и загрузка |

Основание: предоставленный документ «Маппинг_ДобровМГ_5130904-40106.docx». Классы — проектное представление указанных в нём сущностей.
